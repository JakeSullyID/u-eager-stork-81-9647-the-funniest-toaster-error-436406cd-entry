# The Funniest Toaster Error Message

This entry is a lightweight Node 22 program that writes a single deadpan appliance error message to entry.txt, operating entirely deterministically without any external network access or dependencies. Crafting a memorable punchline within strict character constraints relies entirely on surgical precision and unexpected dry humor.

## How to run

Execute the program using Node.js:
\`\`\`bash
node main.ts
\`\`\`

You can optionally specify a custom output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:
\`\`\`bash
MAKEFUN_OUTPUT_DIR=./dist node main.ts
\`\`\`
